# WorkOrder
Work Order is a Mac desktop app. It turns military technical and parts manuals (TM/RPSTL PDFs) into an encrypted, offline database for maintenance planning. It maps symptoms and PMCS results to candidate parts, checks on-hand stock and lead times, builds one combined parts cart, and estimates min/max time to repair. The owner opens the app and unlocks it with a hardware key. Every input is handled as CUI.
