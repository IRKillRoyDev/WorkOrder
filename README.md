# WorkOrder
Work Order is a Mac desktop app for planners and maintenance. You open a work order and choose inspection issues by system from a troubleshooting manual. The app lists the possible repair outcomes and the parts those repairs need, checks on-hand quantities in DSI, SMU, and RIP, and estimates the time to repair. It reads a troubleshooting manual and a parts manual, and it stores the extract in a database file that it encrypts. You unlock that database with a passphrase. Every input is handled as CUI.
